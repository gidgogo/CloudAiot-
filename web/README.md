# 보호자 웹

보호자가 알림과 기기 상태를 확인하는 화면을 넣는 폴더입니다.
SAD 초안은 React를 제안하지만, 현재 프런트엔드 프로젝트나 실행 명령은 아직 없습니다.

구현할 화면은 도움 요청 목록과 처리 상태, 기기 상태, 이벤트 이력, 사용자·기기 설정입니다.
브라우저는 서버 API를 통해 접근하며 카메라나 ESP32를 직접 제어하지 않습니다.

현재 사용할 수 있는 API는 `GET /events?limit=50`과 `POST /events`이며,
서버를 로컬 실행한 뒤 <http://127.0.0.1:8000/docs>에서 데이터 형식을 확인할 수 있습니다.
이벤트는 메모리 저장이고 인증·상태 변경 API·실시간 푸시·브라우저 CORS 설정은 추가 구현이 필요합니다.
개발 서버 포트와 배포 방식이 정해지면 백엔드 담당자와 CORS 및 인증 방식을 맞춥니다.

# ESP32 개발 공간

ESP32에서 실행할 코드를 넣는 폴더입니다. 현재 실행 가능한 펌웨어는 없습니다.

담당 기능은 Wi-Fi·MQTT 연결, 기기별 명령 수신, 릴레이 ON/OFF, command_id 중복 처리,
실행 ACK와 현재 상태 발행입니다. 라즈베리파이의 카메라 코드와 AI 분석 코드는 이 폴더에 넣지 않습니다.

SAD 초안의 MQTT 토픽은 `aiot/{home_id}/{device_id}/cmd`, `ack`, `state`, `lwt`입니다.
최종 페이로드와 재시도 규칙은 서버 담당자와 합의하고 `shared/`에 기록합니다.

Arduino 또는 PlatformIO의 프로젝트 구성, ESP32 보드·릴레이 핀·전기적 동작 조건은 장비 확정 후 추가합니다.
Wi-Fi 비밀번호나 기기 인증 정보는 소스에 커밋하지 않습니다.
